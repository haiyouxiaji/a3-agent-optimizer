# 首批接触恢复

Agent 根据首批在搬运时直立、下降后倾倒且终局未计入的饼干数，从四列中选中第 1 列。它从三组历史档案自动复采 5 局失分和 6 局成功对照。每次干预都运行完两批并计入终局，首批动作时长和第二批启动步数固定。参考沿用已确认的第二批接触恢复控制器。11 个零修正分支的动作、物理末态和计数均与各自的连续参考回合一致。 [协议](protocol.json) · [训练回执](training.json.gz)
