# 第 3 列第二批抓取避让

Agent 从四列确认回执中发现一局夹带第 4 列饼干，选取该局及 4 局正常的第 3 列对照。每个场景复跑完整参考动作，并在第二批闭爪起点比较三个候选轨迹。5 局参考的计分端点和动作哈希均匹配先前的确认回执。 [采集协议](protocol.json) · [逐局回执](training.json.gz)

| 候选 | 指定来源净增 | 减分场景 | 错列场景 | 完整成功退化 |
| --- | ---: | ---: | ---: | ---: |
| 闭爪时横移 3 mm | −5 | 1 | 0 | 1 |
| 闭爪时横移 5 mm | −25 | 5 | 0 | 4 |
| 抬升时横移 5 mm | 0 | 0 | 1 | 0 |

闭爪时横移 3 mm 使错列局恢复完整成功，同时让一局满分对照少搬 5 块。抬升时横移 5 mm 的得分持平，该局仍夹带相邻饼干。Agent 在训练筛选阶段回退。 [拟合比较](fit.json) · [回退回执](result.json)
