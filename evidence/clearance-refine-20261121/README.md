# 首批提前开爪的启用条件

Agent 复采 35 个公开观测前缀，其中 11 个来自上一分支的历史训练，24 个来自已结束的开发对照。每个前缀都核对搬运末端的物理快照和动作哈希。开发场景的配对终局回执用作本轮训练标签，新的评测种子另行预留。 [协议](protocol.json) · [前缀与标签](training.json.gz) · [审计](training-audit.json)

Agent 用公开末端跟踪误差、力觉变化、夹爪开度、预测目标盒朝向及计划批次间距拟合一至两个阈值。六组逐组留出的放置净变化合计 **+22 块**，其中一组的一局少计 **3 块**。Agent 按训练规则拒绝门控，预留开发和确认集保持封存。 [拟合](fit.json) · [决策](result.json)
